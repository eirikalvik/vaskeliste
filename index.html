Personvern og Juridisk Informasjon

Informasjon om datainnsamling, opphavsrett og brukervilkår

🛡️ 1. Hvilke opplysninger samler vi inn?

Denne applikasjonen er bygget etter et strengt prinsipp om dataminimering. Vi samler utelukkende inn de dataene dere selv oppgir for å administrere kollektivets renhold:

  • Kollektiv-identifikator: Valgt kollektivnavn eller adresse (f.eks. «Munkegata 14»).
  • Beboere: Fornavn/kallenavn på beboere i kollektivet for rotasjon av oppgaver.
  • Oppgavestatus: Avkryssinger for ukentlige vaskeoppgaver, egendefinerte oppgaver og datoer for dypvask/sjeldnere oppgaver.
✅ Ingen sensitive data: Vi ber aldri om, og samler aldri inn, passord, betalingskort, e-post, telefonnummer, personnummer eller posisjonsdata.

🔒 2. Hvordan og hvor lagres dataene?

Lokal lagring (standard): Inntil sky-synkronisering aktiveres, lagres alle data 100% lokalt i din egen nettleser via localStorage. Ingen informasjon sendes ut av din enhet.

Sky-synkronisering (valgfritt): Hvis dere aktiverer Google Firebase Firestore for sanntidsdeling mellom beboere, overføres opplysningene kryptert (HTTPS/TLS) til sky-databasen og lagres i henhold til Googles strenge GDPR- og personvernstandarder.

🚫 3. Ingen sporing eller videresalg

Dataene tilhører kollektivet. Vi selger, leier eller deler aldri data med tredjeparter. Det benyttes ingen kommersielle annonsenettverk eller eksterne sporere (som Google Analytics eller Meta Pixel).

🗑️ 4. Sletting og innsyn (GDPR)

Du har full rett til innsyn og sletting:

  • Du kan når som helst slette kollektivets data direkte fra innloggingsskjermen eller ved å tømme nettleserens lagring.
  • Hvis Firebase er tilkoblet, kan dataene slettes direkte i Firestore eller via utviklerdashbordet.

⚖️ 2. Brukervilkår og ansvarsbegrensning

Tjenesten stilles til rådighet vederlagsfritt og «som den er» (as-is). Utvikleren påtar seg intet erstatningsansvar for eventuelle direkte eller indirekte tap, datatap, eller uenigheter som måtte oppstå mellom beboere i kollektivet ved bruk av appen.

🤝 3. Akseptabel bruk

Brukere forplikter seg til å benytte tjenesten til sitt tiltenkte formål og avstå fra å legge inn støtende, ulovlig eller krenkende innhold som kollektivnavn eller oppgavenotater.

🍪 Informasjonskapsler (Cookies) og lokal lagring

Denne nettsiden benytter ingen tradisjonelle sporingskapsler (cookies) for markedsføring eller tredjepartsannonser.

Vi benytter utelukkende funksjonell lokal lagring (Web Storage API / localStorage):

  • vaske_collectives_registry: Husker listen over dine opprettede kollektiv på enheten.
  • vaske_active_collective_id: Husker hvilket kollektiv du sist åpnet for å gi en sømløs brukeropplevelse.
  • vaske_[kollektiv]_...: Lagrer vaskeoppgaver og beboere lokalt på enheten slik at appen fungerer offline.
💡 Denne lagringen er strengt nødvendig for at appen skal fungere, og kan når som helst slettes via nettleserens innstillinger («Slett nettleserdata»).
